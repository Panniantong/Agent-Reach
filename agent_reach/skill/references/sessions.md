# 会话与专用浏览器

用户要登录、退出、换账号，或结果返回 `NEED_LOGIN` 时读这份。

## 专用浏览器

- 所有浏览器渠道共用一个专用浏览器配置，和用户日常的 Chrome 分开；程序不关闭、不修改用户的日常浏览器。
- 内核优先 CloakBrowser；下载或安装失败时用本机已装的 Chrome，并记住这个回退，不每次重下。网络修好后可 `agent-reach browser setup --retry-cloak` 重试。
- `agent-reach add <渠道>` 自动准备 Node、OpenCLI、内核和扩展。工具按本版测试过的版本安装。Windows 上用 Chrome 回退时，可能需要用户点一次"添加至 Chrome"。
- 默认无头，不弹窗。只有 `agent-reach login <渠道>` 会显示窗口；窗口开着时查询直接用这个窗口，不会收掉它，用户登录期间等用户说登好了再查。窗口关闭后，之后的查询回到无头。
- 闲置 10 分钟自动关闭，下次调用自动重开；真实页面操作和 Reach 调用会重置计时。登录期间定期保存，用户不用关窗。
- 可以并行：同一平台最多同时 2 条，所有平台合计 4 条，多出来的排队，最多等 2 分钟，等不到才返回 `BUSY`。同一平台的两次搜索之间至少隔 10 秒。打开登录窗口、退出登录、重装浏览器会等正在跑的查询结束再做。
- `agent-reach browser status` 查看状态，`browser setup` 准备内核和扩展，`browser stop` 关闭程序管理的浏览器。

## 检查与恢复登录

每次使用都验证当前会话；凭据存在不等于有效。视频阅读默认先登录，只有用户明确要求不登录简览才跳过。无需认证的公开渠道不要求登录；其他平台没有实时状态接口时不能报告已验证。

### B 站

- `agent-reach login bilibili --check`：只检查当前托管会话，不创建二维码；查看 `items[0].logged_in`，不要把命令 `ok: true` 当作登录成功。
- `agent-reach bilibili auth`：实时检查，未登录时返回 `NEED_LOGIN` 和 `error.details.login`，其中 `qr_path` 是可展示的本地图片。
- `agent-reach login bilibili`：有效会话自动复用，否则生成或复用尚未过期的官方二维码，非阻塞返回 `items[0]`。立即把图片显示在当前对话，用户本人用 B 站 App 扫码并确认。
- `agent-reach login bilibili --poll`：执行一次有时限的轮询。`waiting_for_scan` / `waiting_for_confirmation` 尚未登录；`expired` 需要重新获取二维码；只有 `logged_in: true, verified: true` 才能继续读取。
- 程序兼容扫码响应中的 Set-Cookie 与旧式跳转查询参数，并在保存新凭据前实时验证。网络失败不会覆盖原凭据或被当成未登录。
- `agent-reach login bilibili --import-existing`：用户明确请求时，一次性导入本机原生 bili CLI 的会话，并验证后保存。不会自动扫描个人浏览器或获取密码。
- 同时发生的请求复用一个有效二维码；不自动无限刷新二维码，不把二维码或凭据发送到第三方。退出登录同时删除未完成的二维码会话。
- `--no-login` 仅供用户明确请求的公开简览：支持 B 站 read/search/hot，不生成二维码，不冒充视频全文分析。

### 其他渠道

使用渠道实际支持的检查和登录入口。用户本人在官方页面完成认证；不代替用户确认，不索要密码，不输出 Cookie。用户明确授权时可从指定来源做一次站点级导入，不保留长期导出授权，不因为浏览器未连接就认定用户未登录。验证码、限流、繁忙和网络错误保留原分类，不换后端绕过。

## 平台差异

- Boss 直聘站内搜索走 OpenCLI，共用专用浏览器。职位详情若因上游误报要求登录，不要让用户反复登录。
- B 站默认在内容请求前验证登录；需要认证时使用上述官方二维码流程，无需启动浏览器。第一分集无可访问字幕不代表其他分集没有字幕。
- 雪球社区动作需要登录；会话几小时内过期，过期后重复登录步骤。

## 退出和删除

- `agent-reach logout <渠道>`：清除专用浏览器里该站的登录和渠道自己的状态，其他网站保留。
- `agent-reach remove <渠道>`：去掉渠道，同时清该站登录和存储，其他网站保留。清理失败时渠道记录保留并返回错误，用户可重试。
- 两者之后都不再自动复制该站登录。
