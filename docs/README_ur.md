## Agent Reach کیوں؟

AI ایجنٹس پہلے ہی انٹرنیٹ تک رسائی حاصل کر سکتے ہیں — لیکن "آن لائن جانے کی صلاحیت" محض آغاز ہے۔

سب سے قیمتی معلومات سوشل اور نچ پلیٹ فارمز پر پھیلی ہوتی ہیں: Twitter مباحث، Reddit تاثرات، YouTube ٹیوٹوریلز، XiaoHongShu جائزے، Bilibili ویڈیوز، GitHub سرگرمیاں… **یہی وہ جگہیں ہیں جہاں معلوماتی کثافت سب سے زیادہ ہوتی ہے**، لیکن ہر پلیٹ فارم کی اپنی رکاوٹیں ہیں:

| مسئلہ | حقیقت |
|------------|---------|
| Twitter API | استعمال کے مطابق ادائیگی، اعتدال پسند استعمال ~$215/ماہ |
| Reddit | سرور IPs کو 403 ملتا ہے |
| XiaoHongShu | براؤزنگ کے لیے لاگ ان ضروری |
| Bilibili | بیرونِ ملک/سرور IPs کو بلاک کرتا ہے |

اپنے ایجنٹ کو ان پلیٹ فارمز سے جوڑنے کے لیے آپ کو ٹولز تلاش کرنے، ڈیپینڈنسیز انسٹال کرنے، اور کنفیگریشنز ڈیبگ کرنے پڑیں گے — ایک ایک کر کے۔

**Agent Reach اسے ایک کمانڈ میں بدل دیتا ہے:**

```
Install Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
```

اسے اپنے ایجنٹ کو دیں۔ چند منٹ بعد یہ ٹویٹس پڑھ سکتا ہے، Reddit تلاش کر سکتا ہے، اور Bilibili دیکھ سکتا ہے۔

**پہلے سے انسٹال ہے؟ ایک کمانڈ سے اپ ڈیٹ کریں:**

```
Update Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md
```

## فوری آغاز

> ⚠️ **OpenClaw صارفین: پہلے `exec` اجازت فعال کریں**
>
> Agent Reach ایجنٹ کے شیل کمانڈز چلانے پر انحصار کرتا ہے (`pip install`, `mcporter`, `twitter` وغیرہ)۔ اگر آپ کا OpenClaw ڈیفالٹ `messaging` ٹول پروفائل استعمال کرتا ہے تو ایجنٹ انہیں نہیں چلا سکے گا۔ **انسٹال کرنے سے پہلے `exec` فعال کریں:**
>
> ```bash
> openclaw config set tools.profile "coding"
> ```
> یا `~/.openclaw/openclaw.json` میں `"tools": { "profile": "coding" }` سیٹ کریں۔ تبدیل کرنے کے بعد Gateway ری اسٹارٹ کریں (`openclaw gateway restart`) اور نئی گفتگو شروع کریں۔ دوسرے پلیٹ فارمز (Claude Code, Cursor, Windsurf وغیرہ) متاثر نہیں ہوتے۔

یہ اپنے AI ایجنٹ (Claude Code, OpenClaw, Cursor وغیرہ) کو دیں:

```
Install Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
```

ایجنٹ Python پیکج انسٹال کرتا ہے، آپ کا ماحول چیک کرتا ہے، اور بتاتا ہے کہ کیا تیار ہے۔ سسٹم سطح کی تبدیلیوں کے لیے واضح `--system` فلیگ درکار ہے۔

> 🔄 **پہلے سے انسٹال ہے؟** ایک کمانڈ سے اپ ڈیٹ کریں:
> ```
> Update Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md
> ```

> 🛡️ **بنیادی طور پر محفوظ:** `agent-reach install` مشین کو چیک کرتا ہے بغیر سسٹم پیکجز انسٹال کیے یا کنفیگریشن لکھے:
> ```
> Safely check and install Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
> ```
> `agent-reach install --system` صرف اس وقت استعمال کریں جب سسٹم تبدیلیوں کی واضح منظوری دی ہوes.

agent-reach install --env=auto
```

<details>
<summary>بطور Skill انسٹال کریں (Claude Code / OpenClaw / کوئی بھی ایجنٹ جس میں Skills سپورٹ ہو)</summary>

```bash
npx skills add Panniantong/Agent-Reach@agent-reach
```

Skill انسٹال ہونے کے بعد، ایجنٹ خود بخود جانچ کرے گا کہ آیا `agent-reach` CLI دستیاب ہے، اور اگر ضرورت ہو تو اسے انسٹال کر دے گا۔

> اگر آپ `agent-reach install --system` کے ذریعے بیرونی ٹولز کو واضح طور پر انسٹال کرتے ہیں، تو skill خود بخود رجسٹر ہو جاتی ہے۔ ڈیفالٹ صرف-پڑھنے والی جانچ موجودہ فائلوں کو نہیں بدلتی۔
>
> صرف انگریزی والی skill فائل چاہیے؟ انگریزی لوکیل سیٹ کریں یا `AGENT_REACH_LANG=en` ایکسپورٹ کریں
> اور پھر `agent-reach install --env=auto --system` یا `agent-reach skill --install` چلائیں۔
> انسٹال شدہ فائل ہمیشہ `SKILL.md` کے نام سے لکھی جاتی ہے، اس لیے زبان تبدیل کرنے کا مطلب ہے
> نئے لوکیل کے ساتھ انسٹال کمانڈ دوبارہ چلانا اور پہلے سے انسٹال شدہ skill فائل کو بدلنا۔
</details>

کسی کنفیگریشن کی ضرورت نہیں — بس اپنے ایجنٹ سے کہیں:

- "یہ لنک پڑھو" → کسی بھی ویب صفحے کے لیے `curl https://r.jina.ai/URL`
- "یہ GitHub ریپو کس بارے میں ہے؟" → `gh repo view owner/repo`
- "یہ ویڈیو کیا کور کرتی ہے؟" → سب ٹائٹلز کے لیے `yt-dlp --dump-json URL`
- "یہ ٹویٹ پڑھو" → `TWITTER_AUTH_TOKEN` / `TWITTER_CT0` سیٹ کریں، پھر `twitter tweet URL` چلائیں
- "اس RSS کو سبسکرائب کرو" → فیڈز پارس کرنے کے لیے `feedparser`
- "GitHub پر LLM فریم ورکس تلاش کرو" → `gh search repos "LLM framework"`

**کوئی کمانڈ یاد رکھنے کی ضرورت نہیں۔** ایجنٹ SKILL.md پڑھتا ہے اور جانتا ہے کہ کیا کال کرنا ہے۔

## ضرورت کے مطابق غیر مقفل کریں

استعمال نہیں کرنا؟ کنفیگر نہ کریں۔ ہر مرحلہ اختیاری ہے۔

### 🍪 کوکیز — مفت، 2 منٹ

اپنے ایجنٹ سے کہیں "میری ٹوئٹر کوکیز کنفیگر کرنے میں مدد کرو" — وہ آپ کو
دستی Cookie-Editor ایکسپورٹ کے مراحل سے گائیڈ کرے گا۔ Agent Reach اقدار محفوظ کرتا ہے تاکہ `doctor` جانچ سکے
کہ آیا کریڈینشلز موجود ہیں؛ `doctor` کوئی `twitter status` نہیں چلاتا۔
براہِ راست `twitter` کمانڈز کے لیے اب بھی اپنے پروسیس ماحول میں `TWITTER_AUTH_TOKEN` اور `TWITTER_CT0`
درکار ہیں۔

XiaoHongShu کے لیے، Agent Reach کبھی صارف کو لاگ اِن نہیں کرتا اور نہ ہی براؤزر کوکیز پڑھتا ہے۔
OpenCLI صرف موجودہ Chrome سیشن استعمال کر سکتا ہے جو صارف کے واضح کنٹرول میں ہو۔
اگر کوئی سیشن موجود نہ ہو، تو لاگ اِن خودکار نہ کریں؛ xiaohongshu-mcp یا کسی پرانے ٹول کے ساتھ
دستی Cookie-Editor ایکسپورٹ استعمال کریں۔ `agent-reach configure xhs-cookies`
OpenCLI یا Chrome میں کوکیز انجیکٹ نہیں کرتا۔

### 🌐 پراکسی — $1/ماہ، صرف محدود نیٹ ورکس کے لیے

زیادہ تر صارفین کو پراکسی کی ضرورت نہیں۔ اگر آپ کا نیٹ ورک Reddit/Twitter بلاک کرتا ہے (مثلاً سرزمین چین) تو ایک حاصل کریں ([Webshare](https://webshare.io) تجویز کردہ، $1/ماہ) اور ایڈریس اپنے ایجنٹ کو بھیجیں — وہ اسے محفوظ کر لے گا اور ان ٹولز کو کال کرتے وقت HTTP(S)_PROXY ایکسپورٹ کرے گا۔

> Reddit کو کسی بھی صورت میں لاگ اِن سیشن درکار ہے — OpenCLI آپ کے براؤزر سیشن پر سوار ہوتا ہے، یا `rdt login` کے بعد rdt-cli۔ Bilibili بغیر پراکسی کے bili-cli کے ذریعے کام کرتا ہے۔

## ڈیزائن کا فلسفہ

**Agent Reach ایک صلاحیت کی تہہ ہے، کوئی اور ٹول نہیں۔**

یہ کسی بھی مخصوص امپلیمنٹیشن سے ایک درجہ اوپر بیٹھتا ہے — یہ **انتخاب، انسٹالیشن، صحت کی جانچ، اور روٹنگ** سنبھالتا ہے، نہ کہ خود پڑھنا۔ پڑھنے کا کام آپ کا ایجنٹ براہِ راست اپ اسٹریم ٹولز کو کال کر کے کرتا ہے؛ کوئی ریپر تہہ نہیں ہے۔

ہر بار جب آپ نیا ایجنٹ بناتے ہیں، تو آپ وقت صرف کرتے ہیں ٹولز تلاش کرنے میں، ڈیپینڈنسیز انسٹال کرنے میں، اور کنفیگز ڈیبگ کرنے میں — ٹوئٹر کون پڑھتا ہے؟ Reddit میں لاگ اِن کیسے کریں؟ بند ہو چکے XiaoHongShu CLI کی جگہ کیا لے؟ ہر بار، آپ وہی کام دہراتے ہیں۔ Agent Reach ایک سادہ کام کرتا ہے: **ہر پلیٹ فارم کے لیے سب سے قابلِ اعتماد رسائی کا راستہ، آپ کے لیے منتخب، انسٹال، اور صحت کی جانچ شدہ۔ رسائی کے راستے آتے جاتے رہتے ہیں (مارچ 2026 میں سنگل پلیٹ فارم CLIز کا ایک گروپ بغیر دیکھ بھال کے رہ گیا — ہم نے راستے بدل دیے)، اس لیے آپ کو فکر کرنے کی ضرورت نہیں۔**

### 🔌 ہر پلیٹ فارم = ایک ترتیب شدہ بیک اینڈ فہرست (پرائمری + فال بیکس)

رسائی کا راستہ بدلنے کا مطلب فہرست کی ترتیب بدلنا ہے، کوڈ دوبارہ لکھنا نہیں۔ `agent-reach doctor` آپ کو بتاتا ہے کہ **ہر پلیٹ فارم فی الحال کون سا بیک اینڈ استعمال کر رہا ہے**۔

```
channels/
├── web.py          → Jina Reader
├── twitter.py      → twitter-cli ▸ OpenCLI ▸ bird
├── youtube.py      → yt-dlp
├── github.py       → gh CLI
├── bilibili.py     → bili-cli ▸ OpenCLI ▸ search API (yt-dlp retired, 412-blocked)
├── reddit.py       → OpenCLI ▸ rdt-cli (no zero-config path, login required)
├── facebook.py     → OpenCLI (desktop browser session)
├── instagram.py    → OpenCLI (desktop browser session)
├── xiaohongshu.py  → OpenCLI ▸ xiaohongshu-mcp ▸ xhs-cli
├── linkedin.py     → linkedin-mcp ▸ Jina Reader
├── rss.py          → feedparser
├── exa_search.py   → Exa via mcporter
└── __init__.py     → چینل رجسٹری (doctor چیکس کے لیے)
```

ہر چینل فائل اپنے امیدوار بیک اینڈز کو ترتیب وار **حقیقی جانچ** کرتی ہے (صرف یہ چیک نہیں کرتی کہ کمانڈ موجود ہے) — پہلا مکمل طور پر کام کرنے والا فعال بیک اینڈ بن جاتا ہے، اور خراب والوں کے ساتھ حل کا نسخہ بھی آتا ہے۔ اصل پڑھائی اور تلاش ایجنٹ کے ذریعے ہوتی ہے جو اپ اسٹریم ٹولز کو براہِ راست کال کرتا ہے۔
